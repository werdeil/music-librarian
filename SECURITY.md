# Security

music-librarian moves and rewrites the files of a music library, and can write to a Lyrion database. A bug that loses or corrupts files, or lets a file name dropped in the Inbox run commands or write outside the library, counts as a security issue.

## Reporting a vulnerability

Please report it privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**. Do not open a public issue.

Include what you ran, what happened, and the smallest example that shows it.

## Supported versions

Only the latest release gets fixes.
